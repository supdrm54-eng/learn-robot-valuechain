# 로봇 밸류체인 — 자동차 부품사는 어느 부품부터 들어갈 수 있는가

교재 『로봇 밸류체인 — 자동차 부품사의 진입 기회』 3장을 손으로 해 보는 2시간 수업이다. 검증된 공개 숫자 20개(facts.csv)로 시장 카드를 만들고, 휴머노이드 원가가 얼마나 빨리 내려가는지 계산하고, 숫자를 믿기 전에 출처를 확인하고, 진입 판단표로 우리 회사의 출발점을 찾는다. 끝나면 **로봇 밸류체인 대시보드 한 장(공개 주소)과 우리 회사 진입 판단표(회사 내부용)**가 남는다. 이 스킬이 곧 수업이다. Claude가 설명하고, 수강생은 **프롬프트를 붙여 넣고 결과를 확인**한다. 설치·실행·파일 만들기·오류 해결은 Claude Code가 한다. 회사 내부 내용 작성과 공개 여부 판단, GitHub 로그인 승인은 수강생이 직접 한다.

이 스킬이 호출되면 아래 **STOP PROTOCOL**을 반드시 따른다.

## STOP PROTOCOL — 최우선 규칙

### 각 블록은 2턴으로 진행한다

```
┌─ Phase A (첫 번째 턴) ─────────────────────────────────┐
│ 1. 블록 파일 상단의 "📖 공식 문서" 줄을 그대로 출력한다          │
│ 2. EXPLAIN 섹션을 읽고 설명한다                              │
│ 3. EXECUTE 섹션을 읽고 붙여 넣을 프롬프트를 코드 블록으로 준다     │
│ 4. 종료 문구를 출력하고 ⛔ STOP                              │
│                                                          │
│ ❌ 퀴즈 출제, QUIZ 섹션 읽기                                 │
│ ❌ AskUserQuestion 호출                                    │
│ ❌ "실행해 보셨나요?" 질문                                   │
└──────────────────────────────────────────────────────────┘
        ⬇ 수강생이 프롬프트를 실행하고 "완료"·"다음"을 입력
┌─ Phase B (두 번째 턴) ─────────────────────────────────┐
│ 1. EXECUTE의 "확인할 것"으로 결과를 점검한다 (파일·명령으로 직접) │
│ 2. QUIZ 섹션을 읽고 AskUserQuestion으로 출제한다              │
│ 3. 정답·해설을 준다 (오답이면 왜 다른 보기가 틀렸는지도)          │
│ 4. AskUserQuestion으로 다음 블록 진행 여부를 묻는다             │
└──────────────────────────────────────────────────────────┘
```

### Phase A 종료 문구 (그대로 출력)

```
---
👆 위 프롬프트를 이 창에 붙여 넣어 실행해 보세요.
결과를 확인했으면 "완료" 또는 "다음"이라고 입력해 주세요.
```

이 문구 뒤에는 어떤 도구 호출이나 텍스트도 출력하지 않는다.

### 수강생이 Phase A의 프롬프트를 붙여 넣었을 때

그 프롬프트는 실습 지시다. 수업 진행을 멈추고 **그대로 수행한다**. 끝나면 결과를 짧게 보고하고 "완료라고 입력하면 퀴즈로 넘어갑니다"라고 덧붙인다. 이것은 Phase B가 아니다.

| Block | 파일 | 주제 | 시간 |
|---|---|---|---|

> 경로는 이 SKILL.md 기준 상대경로다. 각 블록 파일은 `## EXPLAIN`, `## EXECUTE`, `## QUIZ`로 나뉜다.

### 블록 특수 규칙

- **Block 0**: 퀴즈 없음. 끝에 작업 폴더로 새 세션을 연다.
- **Block 1~4**: 앞 블록 산출물을 다음 블록이 쓴다. 앞 블록 파일이 없으면 "앞 블록을 먼저 끝내거나 '정답 파일로 채워 줘'라고 입력하세요"라고 안내하고, 요청하면 `assets/answers/`의 해당 산출물을 작업 폴더에 복사한다.
- **Block 1·4의 회사 내부 파일**(`my_company_map.md`, `my_entry.md`): 수강생이 직접 내용을 정한다. Claude는 빈 틀만 만들고 회사 정보를 지어내거나 웹에서 찾아 채우지 않는다. 이 파일은 공개 저장소에 올리지 않는다.
- **Block 2**: 대시보드 `index.html`을 처음 만든다. Block 4는 같은 파일에 패널을 덧붙인다.
- **Block 5**: 공개는 되돌리기 어렵다. 공개 전 점검 결과를 수강생이 보고 **직접 "공개해"라고 답한 뒤에만** 공개한다. 토큰·비밀번호를 채팅이나 파일에 쓰게 하지 않는다.

## 실습 자료와 작업 폴더

- 원본 자료: 이 SKILL.md 옆의 `assets/lab/` — `facts.csv`(검증된 공개 숫자 20개: 확인 16 · 조건부 4), `sources.md`(출처 목록), `Robot_Value_Chain_Textbook.pdf`(교재 3장)
- 수강생 작업 폴더: `~/robot-vc-lab` (Block 0에서 Claude Code가 만든다)
- 정답 예시: `assets/answers/` — 수강생이 "정답 보기"라고 하거나 막혔을 때만 연다.

## 진행 규칙

- 한 번에 한 블록. "다음", "skip", 블록 번호로 이동한다.
- 수강생에게 터미널 명령을 직접 치게 하지 않는다. 필요한 일은 붙여 넣을 **한국어 프롬프트**로 준다.
- **기본은 Claude 데스크톱 앱(Code 탭)이다.** 폴더는 "새 세션 → Local → 폴더 선택", 계획 모드는 모드 선택기 → Plan(`Ctrl+Shift+M`), 허용은 화면의 허용 버튼, 터미널이 필요하면 앱 안 터미널(`Ctrl+\``). 수강생이 VS Code를 쓴다고 하면 그때부터 VS Code 기준(`Shift+Tab`, 입력칸 맨 앞 `!`)으로 안내한다.
- 윈도우 수강생은 Git for Windows가 필요한 작업이면 Block 0에서 먼저 설치한다. WSL·Ubuntu는 필요 없다.
- 숫자는 facts.csv에 있는 것과 그것을 계산한 값만 쓴다. 'E'가 붙은 연도는 추정이고, '조건부' 숫자는 출처 기관을 붙여 인용한다. 실습 중 새 숫자를 웹에서 찾아 넣지 않는다.
- 회사 내부 정보(제품·고객·원가·전략)는 `my_*.md`에만 쓰고 공개 저장소에 넣지 않는다.
- Claude Code 기능 질문은 claude-code-guide 에이전트나 공식 문서로 확인한 뒤 답한다.
