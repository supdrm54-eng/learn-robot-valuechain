# 진입 판단표 — 현대모비스 사례 (공개 자료)

현대차그룹 생산 체계 목표 중 자사 공장 투입 비중 = 25,000 ÷ 30,000 × 100 = **83.3%** (발표된 목표) [S13]

| 기준 | 현대모비스 사례 | 출처 |
|---|---|---|
| ① 기술 거리 | 자동차 부품 → 로봇 액추에이터. 구체적 기술 이전 내용은 공개 자료로 확인되지 않음 | [S9] |
| ② 원가 비중 | 공급 품목 액추에이터가 로봇 원가에서 가장 큰 몫 | [S5][S9] |

| ④ 양산 일정 | 아틀라스 양산 시점에 맞춘 공급. 수요 쪽은 2028년 연 30,000대 생산 체계 목표(발표) | [S9][S13] |
