# Block 1: 로봇을 해부한다 — 네 부분·세 층·시장 카드

> **Phase A 시작 시 그대로 출력한다:**
> ```
> 📖 공식 문서: https://ifr.org/ifr-press-releases/news/global-robot-demand-in-factories-doubles-over-10-years
> ```

## EXPLAIN

### 1. 로봇은 네 부분으로 읽는다

| 부분 | 사람으로 치면 | 하는 일 |
|---|---|---|
| 센서 | 눈·귀·피부 | 카메라·라이다·힘 감지로 상황 파악 |
| 제어기·AI | 두뇌 | 인식 → 판단 → 동작 계획 |
| 액추에이터 | 근육·관절 | 전기 신호를 움직임으로 — 힘·속도 결정 |
| 엔드이펙터 | 손 | 그리퍼·흡착 등 작업 도구 — 일의 종류 결정 |

자유도(DoF)는 움직일 수 있는 관절 방향의 수다. 휴머노이드는 이 수가 수십 개라 만들기 어렵다(교재 1장, 원본 KMA 로봇 특강 [S6]).

### 2. 가치사슬은 세 층이다 — 왜 층으로 나누는가

| 층 | 무엇 | 지금의 위치 |
|---|---|---|
| ① 하드웨어 — 몸 | 액추에이터·모터·감속기·센서·배터리·골격 | 지금 가장 큰 비용·부가가치 |
| ② 소프트웨어·AI — 두뇌 | 동작 계획·상황 인식·학습 | 장기적으로 가치가 이동 |
| ③ 운영·서비스 | 설치·유지보수·데이터·구독(RaaS) | 로봇이 늘수록 커짐 |

"로봇 시장이 크다"만으로는 할 일이 정해지지 않는다. 부품으로 쪼개야 **우리 제품이 들어갈 자리**가, 층으로 나눠야 **그 자리의 돈이 커지는지 줄어드는지**가 보인다.

### 3. 케이스 — 자동차와 로봇은 쌍둥이다

| 구성 | 자동차 | 휴머노이드 |
|---|---|---|
| 움직임 | 모터·구동계·제어 | 액추에이터·관절·제어 |
| 동력 | 배터리·전력관리 | 배터리·전력관리 |
| 만드는 법 | 대량 조립·품질관리 | 대량 조립·품질관리 |

원본 강의는 이를 "이 강의 전체를 관통하는 핵심 통찰"이라 부르고, 현대차가 새 산업에 '진입'하는 것이 아니라 이미 가진 능력을 옮기는 것이라고 본다 [S6].

## EXECUTE

아래 프롬프트를 붙여 넣으라고 안내한다.

```
robot-vc-lab 폴더에서 1장 실습을 해 줘.

1. data/facts.csv 에서 1장 숫자(장 = 1)만 골라 output/market_cards.md 에 "시장 카드" 3장을 만들어 줘: 세계 신규 설치, 세계 가동 대수, 한국 로봇 밀도. 카드마다 값·단위·기준연도·출처 번호를 원문 그대로 적어 줘. 숫자를 바꾸거나 반올림하지 마.
2. 한국 신규 설치가 세계 신규 설치에서 차지하는 비중(%)을 소수 첫째 자리까지 계산해 카드 아래에 적고, 계산식도 함께 적어 줘.
3. output/my_company_map.md 를 만들어 줘. 표 머리는 [로봇의 부분 / 우리 회사의 관련 제품·기술 / 가치사슬 층 / 비고], 행은 센서·제어기·AI·액추에이터·엔드이펙터. 칸은 비워 둬 — 내용은 내가 직접 채운다. 회사 정보를 지어내거나 검색해서 채우지 마.
4. 끝나면 market_cards.md 내용과 my_company_map.md 의 빈 틀을 보여 줘.
```

수강생이 직접 할 일: `my_company_map.md`의 빈칸을 우리 회사 제품으로 채운다(회사 내부용 — 공개 저장소에 올라가지 않는다).

### 확인할 것 (Phase B)

- `output/market_cards.md`의 숫자가 facts.csv와 같다: 세계 신규 설치 542,000대(2024) [S1], 세계 가동 대수 4,664,000대(2024) [S1], 한국 로봇 밀도 1,012대/종업원 1만 명(2022 데이터) [S3].
- 한국 신규 설치 비중이 5.6%(30,600 ÷ 542,000)다.
- `output/my_company_map.md`가 있고, Claude가 내용을 채우지 않았다(빈칸 또는 수강생이 쓴 내용만).

막히면 원인을 Claude Code에게 찾게 하는 후속 프롬프트를 준다. 정답은 "정답 보기" 요청이 있을 때만 연다.

```
market_cards.md 의 숫자가 facts.csv 와 다르다. 카드별로 facts.csv 의 id, 값(원문), 단위, 기준연도를 나란히 표로 보여 주고 어디서 달라졌는지 찾아 줘.
```

    "header": "Quiz 1",
    "options": [
      {"label": "제어기·AI, 소프트웨어 층", "description": "감속기는 동작을 계획하니 두뇌에 속하고, 가치가 몰려오는 자리다"},
      {"label": "액추에이터, 하드웨어 층", "description": "액추에이터 안의 부품이고 지금 가장 큰 비용 층이지만, 가치가 소프트웨어·운영으로 옮겨 가며 가격 압력을 받는다"},
      {"label": "엔드이펙터, 운영 층", "description": "감속기는 손 끝에 달려 일의 종류를 결정한다"}

정답: 2번. ① 감속기는 모터의 회전을 느리고 힘 있게 바꾸는 장치로 액추에이터 안에 들어가고, 하드웨어 층은 지금 가장 큰 비용·부가가치 자리다. ② 1번은 '움직임'과 '판단'을 혼동했다 — 동작 계획은 제어기·AI의 일이다. 3번은 손(작업 도구)과 근육(구동)을 혼동했다. ③ 현장에서는 "지금 돈이 있는 층"과 "가치가 옮겨 가는 방향"을 함께 적어야 투자 판단이 균형을 잡는다.
