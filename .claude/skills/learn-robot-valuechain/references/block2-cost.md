## EXPLAIN

### 1. 용어

| 용어 | 뜻 |
|---|---|
| BOM(Bill of Materials) | 한 대를 만드는 부품·재료 원가. 여기서는 휴머노이드 하드웨어 원가 |
| 액추에이터 | 모터·드라이브·변속기(감속기)·센서를 묶은 구동 모듈 [S5] |
| 2030E | E = 추정(Estimate). 실제 값이 아니라 기관의 전망 |
| 연평균 증감률(CAGR) | 처음 값에서 끝 값까지 매년 같은 비율로 변했다고 볼 때의 연간 비율 = (끝 ÷ 처음)^(1 ÷ 햇수) − 1 |
| 하한·상한 표현 | "below $17,000"은 상한값이다. 그래서 하락률은 "○% 이상"으로만 말할 수 있다 |

### 2. 왜 계산하는가 — 원가표는 곧 매출표

| 기준 | 숫자를 그대로 옮기기 | 직접 계산해 보기 |
|---|---|---|
| 얻는 것 | "$35,000 → $17,000 미만" | "매년 최소 몇 %씩 싸지나", "물량은 몇 배인가" |
| 판단 | 싸진다 / 커진다를 따로 본다 | 단가 하락과 물량 증가를 **함께** 본다 — 부품 시장 전체는 커지는가? |
| 검증 | 원문을 믿을 수밖에 없다 | 원문에 적힌 성장률과 내 계산을 맞춰 본다 |

부품사에게 원가가 몰린 곳은 매출이 생기는 곳이다. 다만 대당 원가가 빨리 내려가면, 같은 부품을 더 싸게 더 많이 만드는 능력이 없을 때 이익을 지키기 어렵다.

### 3. 케이스 — 원문 숫자를 내 계산으로 확인하기

BofA 원문(2026-03-12)은 휴머노이드 연간 출하가 2025년 20,000대에서 2035년 10 million대로 늘어 "86% CAGR"이라고 적었다 [S5]. 오늘 실습에서 facts.csv의 두 숫자로 직접 계산해 이 86%가 맞는지 확인한다. 원문 숫자를 내 계산으로 한 번 맞춰 보는 습관이, 남의 보고서를 그대로 옮겨 적다가 틀리는 사고를 막는다.

## EXECUTE

아래 프롬프트를 붙여 넣으라고 안내한다.

```
robot-vc-lab 폴더에서 2장 실습을 해 줘. 숫자는 data/facts.csv 에 있는 것만 써.

1. 휴머노이드 BOM: 2025년 $35,000(F06)과 2030E below $17,000(F07)로
   ① 하락률(%) = (35,000 − 17,000) ÷ 35,000 × 100
   ② 연평균 하락률(%) = 1 − (17,000 ÷ 35,000)^(1/5)
   을 소수 첫째 자리까지 계산해 줘. 17,000은 상한값이니 결과를 "○% 이상"으로 적어 줘.
2. 휴머노이드 출하: 2025E 20,000대(F14), 2030E 1.2 million대·2035E 10 million대(F15)로
   ① 2025E → 2030E 배수
   ② 2025E → 2035E 연평균 증가율(%)
   를 계산하고, BofA 원문에 적힌 "86% CAGR"과 맞는지 한 줄로 판정해 줘.
3. 계산식·결과·출처 번호를 output/cost_calc.md 에 표로 정리하고, 마지막에 "단가가 내려가도 부품 시장 전체가 커지는가"를 두 문장으로 써 줘. 추정 연도에는 E를 붙여 줘.
4. robot-vc-lab/index.html 을 만들어 줘. 외부 서버·외부 라이브러리 없이 파일 하나로 열리게, 맨 위에 "공개 자료 기반 · 연도 뒤 E는 추정" 표시, Block 1 시장 카드 3장, BOM 2025 vs 2030E 막대 차트(2030E는 '상한' 표시), 출하 2025E·2030E·2035E 표를 넣어 줘. 숫자 옆에 [S#] 출처를 달고, 휴대폰에서 가로로 넘치지 않게 해 줘.
5. 다 만들면 index.html 을 열어 보여 줘.
```

### 확인할 것 (Phase B)

- `output/cost_calc.md`: BOM 하락률 51.4% 이상, 연평균 하락률 13.4% 이상 (2025 → 2030E).
- 출하 배수 60배 (2025E → 2030E), 연평균 증가율 86.2% (2025E → 2035E) — BofA 원문 86%와 일치 판정.
- 2030E 값 옆에 'E'와 '상한/이상' 표현이 빠지지 않았다.
- `index.html`이 열리고 시장 카드 3장, BOM 막대 2개, 출하 표가 보이며, 숫자마다 [S#]가 있다.

막히면 원인을 Claude Code에게 찾게 하는 후속 프롬프트를 준다. 정답은 "정답 보기" 요청이 있을 때만 연다.

```
cost_calc.md 의 연평균 증가율이 86%와 다르다. 처음 값·끝 값·햇수를 표로 보여 주고, 햇수를 2025E→2035E 10년으로 넣었는지, 1.2 million 과 10 million 의 단위를 제대로 바꿨는지 점검해 줘.
```
