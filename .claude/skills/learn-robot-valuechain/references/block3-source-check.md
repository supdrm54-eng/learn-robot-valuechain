# Block 3: 숫자를 믿기 전에 — 출처 검증

> **Phase A 시작 시 그대로 출력한다:**
> ```
> 📖 공식 문서: https://ifr.org/ifr-press-releases/news/global-robotics-race-korea-singapore-and-germany-in-the-lead · https://institute.bankofamerica.com/content/dam/transformation/physical-ai-part-2.pdf
> ```

## EXPLAIN

### 1. 숫자의 세 가지 상태

| 상태 | 뜻 | 쓰는 법 |
|---|---|---|
| 확인 | 다른 출처로 교차 확인된 숫자 | 출처 번호를 붙여 그대로 쓴다 |
| 조건부 | 한 기관만 낸 고유 추정이라 교차 확인이 안 되는 숫자 | "○○ 추정"을 반드시 붙여 쓴다 |
| 미확보 | 원문을 열지 못했거나 출처가 2차 보도뿐인 숫자 | 쓰지 않는다 |

### 2. 왜 출처를 따지는가 — 숫자 읽는 세 가지 질문

| 질문 | 확인할 것 | 예 |
|---|---|---|
| ① 기준연도 | 지금 값인가, 전망(E)인가 | 2025E 출하 20,000대는 실적이 아니다 [S5] |
| ② 나누는 방식 | 부위별인가, 모듈별인가 | 손 원가: 부위별 약 30%(덱) vs 모듈별 19%(BofA, 2030E) |
| ③ 추정 주체 | 한 기관의 고유 추정인가 | 리니어 액추에이터 27%는 BofA만 낸 숫자다 [S5] |

교재를 만들 때 실제로 쓰지 않은 숫자도 있다. 모건스탠리의 "액추에이터 56%", 골드만삭스의 "2023년 BOM 15만 달러"는 1차 원문을 열지 못해 '미확보'로 남겼다(sources.md 참고).

### 3. 케이스 — 같은 손, 다른 숫자

원본 강의 덱은 휴머노이드 손을 "단일 부위로 가장 비쌀 수도(약 30%)"라고 했고 [S6], BofA는 2030년 모듈별 BOM에서 손을 19%로 본다 [S5]. 둘 다 틀린 것이 아니라 **시점과 나누는 방식이 다르다**. 어느 하나를 골라 단정하면 듣는 사람은 그것을 사실로 받아들인다.

## EXECUTE

아래 프롬프트를 붙여 넣으라고 안내한다.

```
robot-vc-lab 폴더에서 출처 검증 실습을 해 줘. 새로 웹 검색은 하지 마.

1. data/facts.csv 의 '상태' 열 첫 단어(확인 / 조건부)별 개수를 세어 줘.
2. '조건부' 숫자를 모두 골라 [id / 항목 / 값 / 기준연도 / 출처 / 조건부인 이유] 표로 정리하고, 각 숫자를 보고서에 쓸 때의 인용 문장 예시를 한 줄씩 만들어 줘(예: "… 27%(2030E, BofA 추정) [S5]").
3. data/sources.md 에서 '미확보'로 적힌 자료를 모두 찾아 목록으로 적고, 왜 쓰지 않았는지 한 줄씩 옮겨 줘.
4. 손(dexterous hands)의 원가 비중이 두 출처에서 다르게 나오는 이유를 기준연도·나누는 방식·추정 주체 세 질문으로 표에 정리해 줘.
5. 결과를 output/fact_check.md 에 저장하고 요약을 보여 줘.
```

### 확인할 것 (Phase B)

- 상태별 개수: 확인 16개 · 조건부 4개.
- 조건부 숫자 id: F08·F11·F12·F13 — 인용 문장마다 "BofA 추정"과 [S5]가 붙어 있다.
- 미확보 목록에 Morgan Stanley·Goldman Sachs·McKinsey가 들어 있다.
- 손 비중 비교표에 30%(덱, 부위별)와 19%(BofA, 모듈별·2030E)가 함께 있다.

막히면 원인을 Claude Code에게 찾게 하는 후속 프롬프트를 준다. 정답은 "정답 보기" 요청이 있을 때만 연다.

```
fact_check.md 의 상태별 개수가 예상과 다르다. facts.csv 의 '상태' 열을 행마다 그대로 보여 주고, 첫 단어만 기준으로 다시 세어 줘.
```

정답: 1번. ① 1차 원문을 직접 확인했고 출처가 분명하지만, 다른 기관이 같은 방식으로 나눈 숫자가 없다 — 그래서 '조건부'다. 출처와 시점을 붙이면 듣는 사람이 무게를 스스로 판단할 수 있다. ② 2번은 기관의 신뢰도와 숫자의 확정성을 혼동했다. 3번은 지나치게 보수적이다 — 원문을 연 1차 자료는 '미확보'와 다르다. ③ 미확보(원문 미열람)는 쓰지 않고, 조건부(원문 확인·단일 기관)는 조건을 붙여 쓴다.
