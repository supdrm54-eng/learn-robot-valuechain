## EXPLAIN

### 1. 용어

| 용어 | 뜻 |
|---|---|
| 티어(Tier) | 공급망 단계. 완성품 회사에 직접 납품하면 1차, 1차 협력사에 납품하면 2차 |
| 첫 고객(레퍼런스) | 새 시장에서 처음 확보한 납품처. 다음 고객을 설득하는 근거 |
| 양산 전환 | 시제품을 같은 품질로 대량 생산할 수 있게 바꾸는 일 |
| 복합 부품(모듈) | 여러 부품을 묶어 하나로 납품하는 단위 — 로봇 액추에이터는 모터·감속기·센서·제어기의 결합 [S16] |

### 2. 진입 판단표 — 왜 다섯 기준인가

| 기준 | 질문 | 근거(교재) |
|---|---|---|
| ① 기술 거리 | 우리 제품과 로봇 부품의 뿌리가 같은가? | 1장 쌍둥이 표 [S6] |
| ② 원가 비중 | 그 부품이 로봇 원가에서 얼마나 큰가? | 2장 액추에이터 비중 [S5][S6] |
| ③ 첫 고객 | 처음 납품할 곳이 보이는가? | 현대모비스 사례 [S9] |
| ④ 양산 일정 | 고객의 양산 시점에 맞출 수 있는가? | 현대차그룹 로드맵 [S13] |
| ⑤ 원가 하락 대응 | 대당 원가가 내려가도 이익을 내는가? | 2장 BOM 전망 [S5] |

이 표는 교재가 제안하는 틀이다(원본 강의에는 부품사 진입 기준이 따로 없다). "로봇 시장이 뜬다"는 감 대신, 다섯 질문 중 어디가 약한지를 보면 무엇부터 해야 할지가 보인다.

### 3. 케이스 — 현대모비스, 첫 고객을 잡다

현대모비스는 CES 2026에서 보스턴다이내믹스 아틀라스의 양산 시점에 맞춰 액추에이터를 공급한다고 밝혔고, 보스턴다이내믹스는 로보틱스 분야 첫 고객이 됐다 [S9]. 이후 액추에이터 외 다섯 가지 부품 양산 요청도 받았지만 공급은 확정되지 않았다 [S18]. 수요 쪽에서는 현대차그룹이 2028년까지 연 30,000대 로봇 생산 체계를 목표로 제시했다 — 발표된 목표이지 확정 실적이 아니다 [S13].

## EXECUTE

아래 프롬프트를 붙여 넣으라고 안내한다.

```
robot-vc-lab 폴더에서 3장 실습을 해 줘. 숫자는 data/facts.csv 에 있는 것만 써.

1. facts.csv 의 F16(현대차그룹 로봇 생산 체계 목표)과 F17(현대차·기아 공장 투입 목표)로, 생산 체계 목표 중 자사 공장 투입 비중(%)을 소수 첫째 자리까지 계산해 줘. "발표된 목표"라는 표시를 붙여 줘.
2. output/entry_case.md 에 현대모비스 사례로 진입 판단표 5기준(기술 거리·원가 비중·첫 고객·양산 일정·원가 하락 대응)을 채워 줘. 칸마다 근거 출처 번호를 달고, 공개 자료로 확인되지 않는 칸은 "공개 자료로 확인되지 않음"이라고 적어 줘. 지어내지 마.
3. output/my_entry.md 를 만들어 줘. 같은 5기준 표에 [우리 회사 평가(상·중·하) / 근거 한 줄] 열을 두고 칸은 비워 둬 — 내가 직접 채운다.
4. index.html 에 "진입 판단표 — 현대모비스 사례" 패널을 덧붙여 줘. 기존 카드·차트는 그대로 두고, my_entry.md 내용은 절대 넣지 마.
5. 끝나면 entry_case.md 와 대시보드를 보여 줘.
```

수강생이 직접 할 일: `my_entry.md`를 우리 회사 기준으로 채우고, 가장 약한 기준 하나에 동그라미를 친다(회사 내부용).

### 확인할 것 (Phase B)

- 자사 공장 투입 비중: 83.3% (25,000대 ÷ 30,000대, 발표된 목표) [S13].
- `entry_case.md`의 5기준 중 ⑤ 원가 하락 대응은 "공개 자료로 확인되지 않음"이고, 나머지 칸에는 [S#]가 달려 있다.
- `index.html`에 현대모비스 판단표 패널이 추가됐고, `my_entry.md` 내용은 들어가지 않았다.

막히면 원인을 Claude Code에게 찾게 하는 후속 프롬프트를 준다. 정답은 "정답 보기" 요청이 있을 때만 연다.

```
entry_case.md 에 출처 번호가 없는 칸이 있다. 칸마다 근거가 된 facts.csv id 나 sources.md 번호를 찾아 표로 보여 주고, 근거가 없으면 "공개 자료로 확인되지 않음"으로 바꿔 줘.
```

정답: 2번. ① 첫 고객은 신뢰가 쌓인 관계에서 나오기 쉽다. 이미 거래 중인 고객이 로봇을 도입·생산할 계획이 있다면, 기존 부품과 기술 거리가 가까운 품목부터 제안하는 것이 진입 장벽이 낮다. ② 1번은 부품사가 로봇 전체를 만들 필요는 없다는 교재 3장의 출발점과 어긋난다. 3번은 ④ 양산 일정을 ③ 첫 고객보다 앞세운 것으로, 수요 확인 없는 설비 투자 위험이 크다. ③ 판단표는 순서가 있다 — 첫 고객 → 양산 → 다음 부품.
